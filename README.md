## What I'm building

### [OpenLog](https://openlog.kr)

> Keep the context behind the code, then turn it into durable knowledge.

OpenLog is a workspace built for developers and AI coding agents. It keeps tasks, decisions, logs, memories, and outputs connected, then turns that working context into technical knowledge that others can review and improve.

I currently build and operate OpenLog. If you are interested in agentic development or AI-native workflows, [take a look at OpenLog →](https://openlog.kr)
